Free publishing:
1. Create a free GitHub account.
2. Create a new public repository named top-notch-mobile-detailing.
3. Upload index.html and styles.css.
4. In Settings > Pages, choose Deploy from branch, select main / root, and save.
5. GitHub will give you a free website address.
